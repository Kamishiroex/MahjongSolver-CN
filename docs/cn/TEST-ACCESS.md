# 可选测试版验证

标准求解器、手动提醒、自动打牌、任务、排队、评分读取、设置和普通诊断不要求测试验证，仍保留各自的版本、登录、数据、动作和运行授权检查。

验证入口位于“设置 → 测试版”。本地验证有效七天，重复验证不续期；验证成功只授予测试能力，不切换来源、不预热、不开始或恢复任务。用户需主动选择测试版并明确启动。导入只保存资源。重载默认标准且未启动，保留已有配置和模型。

标准运行不受测试资格变化影响。正在使用测试版时资格失效，会暂停相关动作和排队、保留任务计数并丢弃迟到结果，不静默切换标准来源。重新验证不会自动继续；用户可以主动选择标准求解器，再预检继续同一任务。

租约保存在插件本机配置目录的 `test-access.json`。输入值不写入配置、诊断或日志，也不上传。这里只是本地测试入口限制，不是联网授权或防篡改系统。公开测试使用合成输入，不能把它当作实际凭据。

权限边界与迟到结果回归见 `CapabilityAccessFeature`、`AkochanGlobalPolicy` 及对应 gameplay 测试。标准行为测试须实际进入运行模式并调用上游策略，同时断言测试工厂零调用，不能只检查按钮可见。
