# 可选测试版验证

标准模式不执行游戏操作，仅提供提示。默认上游求解器；完整界面、主题、提示任务、目标提醒、已显示资料页的只读评分、本地记录、设置和普通诊断不要求测试验证，保留正常版本、登录和数据检查。

验证入口位于“设置 → 测试版”。本地验证有效七天，重复验证不续期；验证成功只授予资格，不切换来源、不预热、不开始或恢复任务。资格有效时测试求解器与游戏操作直接可用，无逐项能力开关；点击启动或继续才授予本次任务权限。上游自动同样需要资格。导入只保存资源，不切换来源或启动任务。已经明确选择 Mortal 且资格有效时，恢复来源或切换所选资源会后台预热；不会主动出牌或排队。

标准提示不受测试资格变化影响。过期前已经启动的最后一个任务保留资格，包含无限循环和同一任务暂停后继续；不改变其角色、来源、规则或计数。界面提示到期，结束任务、重载或换源后新任务需要重新验证。没有有效原任务时，资格失效会暂停相关动作并丢弃迟到结果，保留所选来源，不静默切换。重新验证本身不自动继续。

运行授权仅存内存，绑定任务 ID、当前角色的会话内匿名上下文及撤销代数，不写回配置。UI、命令、延迟框架回调、任务协调器和实际输入边界均重新检查；暂停、换源、撤销或失去任务资格后不能通过续期/重新启用复活旧请求。只读评分与窗口导航分开：本次评分窗口按钮只授权该请求，整场后台刷新要求仍有效的任务授权，失效后不关窗或切页。独立评分授权不会允许打牌或排队。

租约保存在插件本机配置目录的 `test-access.json`，来源偏好单独保存在 `solver-preference.json`，后者仅含格式版本与是否选择测试版，不包含启动授权。输入值不写入配置、诊断或日志，也不上传。这里只是本地测试入口限制，不是联网授权或防篡改系统。公开测试使用合成输入，不能把它当作实际凭据。

权限边界与迟到结果回归见 `CapabilityAccessFeature`、`AkochanGlobalPolicy` 及对应 gameplay 测试。标准行为测试须实际进入运行模式并调用上游策略，同时断言测试工厂零调用，不能只检查按钮可见。
