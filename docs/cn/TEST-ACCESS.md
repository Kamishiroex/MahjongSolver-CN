# 可选测试版验证

标准模式不执行游戏操作，仅提供提示。默认上游求解器；完整界面、主题、提示任务、目标提醒、已显示资料页的只读评分、本地记录、设置和普通诊断不要求测试验证，保留正常版本、登录和数据检查。

验证入口位于“设置 → 测试版”。本地验证有效七天，重复验证不续期；验证成功只授予资格，不切换来源、不预热、不开始或恢复任务。两个能力独立控制：实验求解器改变建议来源；游戏操作能力允许授权自动打牌、结算、报名、匹配确认、退桌和连续任务，使用上游求解器时同样需要。操作能力本次加载默认关闭、不持久化；每次启动/继续任务还需明确授权。导入只保存资源。重载保留明确选择的求解来源和资源，但保持未启动。

标准提示不受测试资格变化影响。测试求解或游戏操作中资格失效，会显示续期提醒，暂停相关动作和排队、保留任务计数并丢弃迟到结果。原选择保留，不静默切换标准来源。重新验证不会自动继续。即使切回上游，自动操作仍需有效资格、操作能力和本次任务授权。

运行授权仅存内存，绑定任务 ID、当前角色的会话内匿名上下文及撤销代数，不写回配置。UI、命令、延迟框架回调、任务协调器和实际输入边界均重新检查；暂停、换源、撤销或过期后不能通过续期/重新启用复活旧请求。只读评分与窗口导航分开：本次评分窗口按钮只授权该请求，整场后台刷新要求仍有效的任务授权，失效后不关窗或切页。独立评分授权不会允许打牌或排队。

租约保存在插件本机配置目录的 `test-access.json`，来源偏好单独保存在 `solver-preference.json`，后者仅含格式版本与是否选择测试版，不包含启动授权。输入值不写入配置、诊断或日志，也不上传。这里只是本地测试入口限制，不是联网授权或防篡改系统。公开测试使用合成输入，不能把它当作实际凭据。

权限边界与迟到结果回归见 `CapabilityAccessFeature`、`AkochanGlobalPolicy` 及对应 gameplay 测试。标准行为测试须实际进入运行模式并调用上游策略，同时断言测试工厂零调用，不能只检查按钮可见。
