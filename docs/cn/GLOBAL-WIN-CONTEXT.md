## 真正传入引擎

akochan 基底仍为 `53188a0b926fbab38177f88c3cd87d554cf412af`。`selector.cpp` 原当前自摸分支只传海底附加番，原荣和分支只传河底/抢杠附加番。新增本地桥接 `mjcn-public-snapshot-v2`：

- `OwnDrawKind` 进入规范化输入、缓存摘要及原生回执，已确认岭上给当前自摸估值增加1番，不与海底叠加。
- 已成立立直且已确认的一发资格，进入当前荣和/自摸附加番；未知不当成有效。**本次没有宣称补齐正向一发资格的实机识别。**
- 仅改变当前和牌分支，不把本轮附加番套用到模拟的未来摸牌。
- 托管端核对原生实际收到的摸牌来源、一发值及附加番，矛盾或回执不符拒绝使用。

规则语义依据 [FFXIV 官方役种表](https://na.finalfantasyxiv.com/lodestone/playguide/contentsguide/goldsaucer/doman-mahjong/yaku_list/) 的 After a Kan、Ippatsu、Last-tile Draw；来源用于规则，不替代国服字段/时序验证。未知摸牌来源保留原海底估值假设并显示原因。旧 v1 引擎继续兼容，但明确提示尚未使用新增附加番。

本机新引擎已单独构建到 `engines/akochan-global-v2`，0.6.1.8加载时优先选择此目录，仍核验完整清单与文件哈希。旧 `akochan-global` 未覆盖。其他机器使用源码命令独立构建：

```powershell
./scripts/setup-akochan.ps1 -GlobalSnapshot -Destination "$env:APPDATA/XIVLauncherCN/pluginConfigs/Mahjong.Plugin.CN/engines/akochan-global-v2"
```

插件ZIP不包含受独立许可证约束的 akochan 二进制或参数。
