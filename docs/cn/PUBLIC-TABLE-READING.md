# 当前公开牌河与副露图像读取

本轮读取的是正常桌面上当前可见的公开图像，供事件记录和已有实验状态的核对使用。它不扫描暗手资源，不调用游戏操作，不把渲染槽位解释成完整历史。旧文档中的 metadata-only 是当时实现范围；本轮在同一固定版本与 ULD 门下，明确增加四方公开牌河及副露的当前选中正面资源读取。

实现与合成回归已准备，最终构建和测试结果由发布报告记录。本文件不宣称新增区域已经完成国服逐张实测。

## 几何实录复核

旧实录 E、F 的完整数值父链按固定公式离线投影，不读取或输出牌面序列：

| 实录 | 完整 face/shell 变换样本 | 与 ScreenX/Y 原点最大轴误差 | 累积矩阵最大元素误差 |
| --- | ---: | ---: | ---: |
| E | 25,022 | 0.000191 像素 | 8.20×10⁻⁸ |
| F | 1,982 | 0.000217 像素 | 1.57×10⁻⁷ |

D 有 12,766 条相关记录缺少局部 X/Y，不能反推补齐。复核结果表明：旋转图像的 `ScreenX/Y` 是局部原点经完整祖先变换后的坐标，并不是旋转包围框的最小 X/Y。读取器因此比较原点缓存（允许 0.5 像素误差），另计算包围框用于遮挡检查。矩阵采用已观察的行/列约定核对累积旋转缩放，拒绝过渡中的不一致值。

完整 actual ancestry、尺寸、有限数值、固定旋转/反射以及缓存检查都发生在资源读取之前。其他公开槽的壳与当前 face 相交，或有可见背壳遮挡时，不读取被遮挡 face。浮点边缘误差容差为较小尺寸的 1%，不是将叠牌自动当成合法加杠。只有这些几何门通过后，才依次读取正面壳、face 当前选中 Part、该 Part 的 Asset，最后读取同一资源的 `TexPathHash` 和 `IconId` 两个标量。牌义要求二者同时匹配已审阅目录；不读取路径字符串、其他未选中 Parts 或贴图像素。

## 交付的数据边界

`PublicTableFaces` 是本次读取的槽位及错误，`PublicTableReading.Tiles` 是可解码的当前图像。每张保留区域、屏幕方向、`SlotPath`、`GroupPath`、屏幕边界、旋转、镜像、牌种和赤五标志。质量始终为 `Candidate`；独立两次相同采样可以将当前图像标为 Stable，不能将区域语义升级为已实测完整牌河。任何消失、变化、读错、重复序号和场景退出都清除旧结果，不沿用上一帧缺失的牌。

四河 `Areas` 另行记录固定顶层容器存在、实际祖先地址匹配、容器可见、整个有界遍历完成、可见槽数和未知组件数。空区域也须通过容器及祖先的有限正均匀缩放、零旋转、累积矩阵及原点缓存检查，折叠或过渡失配保持未知。未读区域不补成空数组。只有当前 ready/visible Emj、固定容器链存在、遍历成功且没有未解释可见组件时，零槽才记为 `ObservedEmptyCandidate`；隐藏的存在容器单独保留 `ContainerVisible=false`，其区域 Stable 始终为 false，不能单凭隐藏空候选授权恢复。稳定空候选也不证明本局未有人弃牌。旧记录没有 `Areas` 时保持缺证据。

`MeldGroups` 按当前组根分组，保留可见槽数、已解码数量、错误和两帧稳定状态。只有当前 3 或 4 个可见槽均已解码才有 `AllVisibleSlotsDecoded=true`。可见的第四子组件、背壳、缺 face 或缺 shell 会留下明确拒绝槽，不能把未知的新加杠当成上一份三枚碰。组完全可见也不自行判断吃、碰、明杠、暗杠、加杠或来源座位；暗杠背牌不补猜。

`CurrentDisplayComplete` 和 `HistoryComplete` 都保持 false。当前画面无法恢复被鸣走的弃牌、漏采过渡、隐藏槽、绝对座位、立直事件时点或完整开局。屏幕方向不是门风。现有实验状态可与独立观察核对，但不能因此成为完整 AI 已验证输入。

## 本地事件日志分析

使用 [analyze-game-logs.py](../../scripts/analyze-game-logs.py) 分析插件日志目录、单次 `mjcn-game-*` 目录，或窗口导出的日志 ZIP。只访问 `events.jsonl`、`errors.jsonl`，ZIP 不解包；输出须是输入目录之外的新文件，不覆盖现有文件。

```powershell
python scripts/analyze-game-logs.py "日志目录或导出ZIP" --output ".work/game-log-summary.json"
python -m unittest discover -s tests -p test_analyze_game_logs.py -v
```

脚本按每个流独立验证序号、会话与 SHA-256 前链；哈希直接使用 `Entry` 值在原始 UTF-8 行中的精确子串，不重新序列化改变转义。只有最后未换行的尾部可以恢复完整前缀，输出 `Partial` 并返回退出码 2；完整坏行、重复键、超限、错序或哈希不符返回 1，正常已验证前缀返回 0。通过哈希不代表牌局历史完整。

summary 仅含版本、各类事件计数、`history_gap`、恢复结果计数、错误码与时间范围，不输出账号、聊天、原始路径、原因原文或完整牌面。尚未支持的新事件名以不含原文的摘要键计数。首次实现的 Python 合成测试已执行通过；最终完整构建还会统一运行这些测试。
