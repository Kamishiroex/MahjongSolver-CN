# 0.6.0.2：当前公开牌局全局 AI

本版把已采集的公开牌局送进 akochan 的原生全桌评估器，替换 0.5.x 仅分析门清14张手牌的实验策略。顶部选择“实验全局 AI”，再选手动提醒或自动打牌。不会因 AI 失败偷偷回退上游；“上游牌效”仍可单独选择。

这里的“全局”指输入范围和决策范围，不代表完整历史已经采集，也不代表达到某个实战强度。

0.6.0.1修复可碰菜单长期等待：响应绑定到已观察到的公开弃牌和当前菜单，在该窗口持续期间保留；上游候选推断不再决定鸣牌来源。相同分类内的高亮亮度变化不再打断牌面稳定，也不再重复写入完整快照。[修复说明](CORE-VALIDATION.md)。

0.6.0.2进一步修复共用恢复链：一次读失败或错过开局不再阻止整局后续事件。局内观察段与权威RoundId分开，当前公开身份连续确认后重新建基线，只记录其后的真实变化。静态响应菜单只能按当前可见牌河、手牌和吃碰杠规则唯一确定来源时推导，并标明未观察到的触发事件；有歧义或真实事件冲突会显示具体原因。摸切／被鸣未知项仍保持未知。详见[本版说明](CORE-VALIDATION.md)与[真实吃牌回放](../../tools/Mahjong.Cn.ChiResponseProbe/README.md)。

## 输入和决策

- 输入自己的可见手牌（含赤五）、四家牌河及已知摸切／被鸣标记、公开副露、宝牌指示牌、场风／局数、本场／供托、四家座位和点数、立直状态、余牌以及已观察到的部分事件。
- 多玛式显示实际宝牌时，按显示模式转换为指示牌。当前候选读值可以用于实验分析，但会列入假设；相互矛盾的值仍会阻止分析。
- 对手暗手没有输入字段，不读取背牌的隐藏牌面。过去没捕获的顺序不编造为完整 mjai 牌谱。
- 原生返回排序候选：弃牌、立直、吃、碰、明杠、暗杠、加杠、荣和、自摸、放弃。当前游戏允许的动作与牌面再做核对。吃碰后的弃牌在游戏确认后按新快照重算，不提前执行整个动作批次。
- 赤五和摸切／手切弃牌保留具体身份；吃牌组合遵循 AI。赤牌鸣牌存在无法精确指定的多种物理组合时，该候选仍禁用。
- 不使用旧上游牌效先决定和牌或鸣牌；AI 候选不可执行、引擎出错或超过10秒则暂停。等待计算不会被当成“放弃”。
- 场景退出、输入冲突、读取异常、版本不符或状态变化会丢弃旧结果。自动仍需主动开启。

缺失的临时振听、一发资格、首巡和事件顺序可能影响评估。未知一发按无一发估值，未知摸切按手切估值；供托／点数等缺失值和规则默认值会逐项显示。可见立直棒不等于捕获了“立直成立”的准确时刻。本家副露不完整或手牌数量矛盾会等待新读取；对手读取缺口在假设中列出。

## 本机引擎安装

固定 akochan 提交：53188a0b926fbab38177f88c3cd87d554cf412af。使用本项目编写的当前状态入口补丁，在本机生成独立引擎；原生源码、参数、DLL、EXE 不包含于发布 ZIP。保留其独立许可证，见[许可核查](AKOCHAN-LICENSE-BUILD.md)。

在源码根目录执行（需要已有 VS C++ x64 工具链和 Windows SDK）：

~~~powershell
$globalEngine = Join-Path $env:APPDATA 'XIVLauncherCN\pluginConfigs\Mahjong.Plugin.CN\engines\akochan-global'
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/setup-akochan.ps1 -GlobalSnapshot -BuildDirectory .work/akochan-global-build -Destination $globalEngine
~~~

脚本拒绝覆盖非空目录。已有全局引擎升级时先停止插件并保留旧目录，选择一个新的构建目标，验证后再替换。旧 engines/akochan 不能作为本版全局入口；它仍可用于公开样例自检。插件不会自动下载引擎。

本机已实际使用 MSVC 14.29.30133、Windows SDK 10.0.19041.0 构建全局补丁并验证。补丁身份包含固定源码 SHA256；缺少或不匹配时报具体错误，未关闭身份检查。当前快照管道保持进程存活至宿主关闭，避免输出后退出与 EOF 检测竞争。

## 日志与实现边界

AI 页展示最近实际输入、缺口和候选评分；“导出最近一次 AI 输入与结果”导出完整结构化快照。/mjcn logs 导出事件与错误双日志。大 AI 条目使用 global_ai_trace_chunk，按 TraceId、Index 排序，把 Data 逐块 Base64 解码后拼接为完整 UTF-8 JSON；完整记录没有被静默截断。

当前状态通过 start_kyoku 携带 mjcn_snapshot **传输包**直接进入原生 Game_State，不冒充真实开局手牌。历史只附已观察到的弃牌和鸣牌，立直棒与摸牌候选 UI 信号不伪装成权威事件。鸣牌后入口的替代触发标记为 mjcn_after_call，不记作真实摸牌。原生公开计数为副露补入未被牌河覆盖的同一张被鸣牌，避免漏算／重复计数。

完整源码包包含独立补丁脚本、原生入口与 include 文件，保留旧标准回放接口和兼容性检查。原生输出不能直接驱动输入；仍由当前合法动作、物理牌槽和停止状态共同约束。
