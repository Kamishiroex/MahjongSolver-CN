# 验收范围与步骤

按本次构建对应的 `build-manifest.json`、源码提交及固定版本依赖验收；编译通过不代表国服读牌或操作正确。历史版本的观察仅适用于其记录的版本与场景。字段与动作依据保留在相应 evidence 文档和脱敏回归样例中。

## 自动验证

运行 `scripts/build-cn.ps1`：现有 .NET 与 Python 回归、文档链接、源码清单检查、源码 ZIP 重建及逐 DLL 比对。显式提供合法本机引擎和回放文件才运行对应原生/重放测试，缺少时标记未执行。UI 宿主调用生产 ImGui Draw，100/150/200%与紧凑模式截图属于合成状态，不是实机读数。

## 国服实机

1. 全新配置、无测试码、无模型：直接进入五页新界面，默认标准且未启动；无整页锁定、验证码专页或模型安装警告。检查中文、窄窗、紧凑、缩放、主视口内外显示与主题恢复。
2. 无资格、无模型时主动启动标准提示，确认测试后端零创建/预热/推理且没有游戏输入；命令或恢复旧配置也不能开启自动。验证失败/过期不影响标准提示。仅验证成功不选择任何能力；实验求解器可单独提示，操作能力必须另外启用和授权本次任务，即使用上游也一样。测试操作的 UI、命令、延迟回调、排队、确认、结算、退桌逐一核对。暂停/撤销后旧请求不能因续期或重启复活。重载保留求解来源，但操作能力关闭；到期提醒暂停、丢弃旧结果、不自动换源。继续同一任务须重新授权，不清空场数、时间和本场后停条件。
3. 入桌、开局、连续摸弃、排序、赤五、宝牌，四家牌河与副露；吃碰后出牌、明杠/暗杠/加杠、立直、荣和、自摸、流局和特殊流局。分别记录牌面正确与建议质量；过渡时不得重复记牌或沿用上一局。
4. 连续换局、队友等待、整场退出、插件重启和公开日志恢复。暂停后无新动作，继续同一任务保留计数；一场是整场东风/半庄，重复完成事件不重复计数。
5. 场数、有效时长、截止日期、本场后停在整场边界阻止下一次排队/确认。正常任务结束不冒充故障；真正故障仍告警。
6. 标准模式手动打开金碟／方城战页后点击“读取已打开页面”，仅读取、不切页或关窗；页关闭时不得自动打开。验证并启用操作能力后，在测试版设置明确授权本次窗口刷新，才允许开页、切页、读分并关闭自己打开的页。已有用户窗口保留。整场后自动刷新必须来自仍有效的授权任务，标准提示结束不得触发。重复点击、失效、全停、换角色和切场景不能重复操作、沿用异角色数据或接收迟到结果。对照当前评分、最高评分、段位与“总场数”；分别记录开局前与完成后的计数。只有恰好增加 1 才允许对应整场差值；旧计数不得算作零变化，两帧相同不能证明服务器已更新整场结果。最终名次需单独验证，评分目标、掉分及连续第四名规则仍保持不可启用。
7. 本人结算行逐项核对（含同分、姓名缩写/隐藏、只读旁观、提前退桌）；荣和/自摸/流局、本人放铳、多响、包牌与特殊流局分别检查。详情关闭后的付款动画不得提前定值，重复帧/等待队友不重复记局。中盘重载/缺少前值显示未知，旧日志不被补成零胜零负。结算前/后切换任务、角色及日志归档不得串场。
8. 断网、统计接口失败不能影响本地能力；未同意不得心跳。分享摘要不含个人标识，详细导出主动脱敏，原始本机日志不改写。
9. 短暂读取中断后保持同桌：界面显示重新核对，稳定后沿用原模式；手动暂停、过期、退出或重复提交风险不得恢复，失败必须提醒。禁用恢复后普通停止路径不变。每分钟超过三次不应循环开打；结算等待不应误触发排队。
10. 结算期间测试日志文件暂时不可写，恢复可写后补存；卸载重载能发现已暂存结果。关闭/重开战绩页、筛选后有效分母与明细一致。末局隐藏四家面板时，最终行必须按真实名字临时比较回座位；同名/隐藏/缺字段保持未知。未取得赛前证据时评分差值仍未知。

## 已知边界

最终名次及赛后评分/总场数字段已在锁定客户端取得只读样本并由用户核对；实际荣和付款过渡、末局自摸和最终座位对应已加入离线回归。新统计加载后的完整对局、评分关联、归档及显示，以及错误自动恢复仍待实机验收；其他小局结果和特殊支付不冒称已实测。不保证建议质量，社区服务未部署。详情见 [关键回归](CORE-VALIDATION.md)、[公开输入缺口](PUBLIC-INPUT-GAPS-20260925.md) 与 [完整历史契约](LIVE-AI-INPUT-COMPLETENESS.md)。

## 回退

先停止全部并卸载候选，再加载旧包，同身份只加载一份。保留模型与配置，必要时恢复外观备份。旧版可能仍有旧的全局验证或默认模型行为，回退后先确认自动关闭；外观恢复不能绕过任务和动作检查。
