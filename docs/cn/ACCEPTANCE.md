# 验收范围与步骤

按本次构建对应的 `build-manifest.json`、源码提交及固定版本依赖验收；编译通过不代表国服读牌或操作正确。历史版本的观察仅适用于其记录的版本与场景。字段与动作依据保留在相应 evidence 文档和脱敏回归样例中。

## 5.2.1.1 新框架验收

自动回归覆盖兼容小更新不依赖提交白名单、结构/签名改变阻止读取、API/游戏/运行时变化阻止读取、历史日志来源与公开布局保留；契约还核对发布 DLL 的全部相关框架引用。构建/源码重建及实际测试结果以发布附件 `build-manifest.json` 为准。

本次新框架的实机加载与完整麻将对局仍待验证：更新插件后检查 `/mjcn` 的界面、评分刷新和建议高亮；入桌观察开局、鸣牌、和牌、跨局和退桌，再确认连续任务/双桌型报名及停用重启。若出现 `VERSION_CONTRACT`，回传普通诊断中的版本与错误即可，不要求用户研究结构。合成界面渲染及旧牌局回放不替代上述验收。

## 自动验证

运行 `scripts/build-cn.ps1`：现有 .NET 与 Python 回归、文档链接、源码清单检查、源码 ZIP 重建及逐 DLL 比对。显式提供合法本机引擎和回放文件才运行对应原生/重放测试，缺少时标记未执行。UI 宿主调用生产 ImGui Draw，100/150/200%与紧凑模式截图属于合成状态，不是实机读数。

## 国服实机

1. 全新配置、无测试码、无模型：直接进入五页新界面，默认标准且未启动；无整页锁定、验证码专页或模型安装警告。检查中文、窄窗、紧凑、缩放、主视口内外显示与主题恢复。
2. 无资格、无模型时主动启动标准提示，确认测试后端零创建/预热/推理且没有游戏输入；命令或恢复旧配置也不能开启自动。验证失败/过期不影响标准提示。资格有效时全部测试功能直接可用，无额外能力开关或授权按钮；验证本身不切源、预热、开打或排队。点击普通自动按钮或启动任务后才运行；UI、命令、延迟回调、排队、确认、结算、退桌均检查资格与任务上下文。暂停后旧请求不能因续期或重启复活。重载恢复有效资格与求解来源，但不启动任务。过期前已启动的原任务保留，有限场数与无限循环均可继续；正常暂停仍撤销操作，继续同一任务不清空场数、时间和本场后停条件。绑定原任务、角色、模式、来源与规则，不转移到新任务；结束或重载后需重新验证。没有实际任务的旧请求到期撤销，续期不复活；不得静默换源。`TestAccessEntryTests` 覆盖无资格、资格生效、重载、一次启动、过期续期及迟到请求；新交互仍待游戏内验收。
3. 入桌、开局、连续摸弃、排序、赤五、宝牌，四家牌河与副露；吃碰后出牌、明杠/暗杠/加杠、立直、荣和、自摸、流局和特殊流局。分别记录牌面正确与建议质量；过渡时不得重复记牌或沿用上一局。
4. 连续换局、队友等待、整场退出、插件重启和公开日志恢复。暂停后无新动作，继续同一任务保留计数；一场是整场东风/半庄，重复完成事件不重复计数。
5. 场数、有效时长、截止日期、本场后停在整场边界阻止下一次排队/确认。正常任务结束不冒充故障；真正故障仍告警。
6. 无测试资格时手动打开金碟／方城战页后点击“读取已打开页面”，仅读取、不切页或关窗；页关闭时不得自动打开。有资格时总览显示“刷新本人评分”，点击后直接开页、切页、读分并关闭自己打开的页，不再到设置里启用或授权。已有用户窗口保留。整场后自动刷新必须来自仍有效的运行任务，标准提示结束不得触发。重复点击、失效、全停、换角色和切场景不能重复操作、沿用异角色数据或接收迟到结果。对照当前评分、最高评分、段位与“总场数”；分别记录开局前与完成后的计数。只有恰好增加 1 才允许对应整场差值；旧计数不得算作零变化，两帧相同不能证明服务器已更新整场结果。最终名次需单独验证，评分目标、掉分及连续第四名规则仍保持不可启用。
7. 本人结算行逐项核对（含同分、姓名缩写/隐藏、只读旁观、提前退桌）；荣和/自摸/流局、本人放铳、多响、包牌与特殊流局分别检查。详情关闭后的付款动画不得提前定值，重复帧/等待队友不重复记局。中盘重载/缺少前值显示未知，旧日志不被补成零胜零负。结算前/后切换任务、角色及日志归档不得串场。
8. 断网、统计接口失败不能影响本地能力；未同意不得心跳。分享摘要不含个人标识，详细导出主动脱敏，原始本机日志不改写。
9. 短暂读取中断后保持同桌：界面显示重新核对，稳定后沿用原模式。过期后仍有效的原任务可恢复；手动暂停、任务权限失效、退出或重复提交风险不得恢复，失败必须提醒。禁用恢复后普通停止路径不变。每分钟超过三次不应循环开打；结算等待不应误触发排队。
10. 结算期间测试日志文件暂时不可写，恢复可写后补存；卸载重载能发现已暂存结果。关闭/重开战绩页、筛选后有效分母与明细一致。末局隐藏四家面板时，最终行必须按真实名字临时比较回座位；同名/隐藏/缺字段保持未知。未取得赛前证据时评分差值仍未知。

11. 游戏手牌建议高亮：任意缩放、重排、普通/赤五、摸切/手切、立直后分别核对；过渡、读数过期、牌面不一致和暂停后立即消失。高亮不生成游戏输入。
12. 在牌桌外选择已安装 Mortal，观察后台准备，完成前不得报名、确认或开打；东家首手、跨局常驻、暂停/继续、全停释放、切模型重新准备分别核对。仅验证资格不得预热或开打。UI 状态区区分准备、正常等待、恢复、暂停和需要接管。
13. 一次勾选两个同类桌型，任务搜索器应同时出现两项；匹配任一所选桌型可进入，退出后继续双报名。非所选或临时更改的队列不得接管；整场计数、实际桌型与退桌身份一致。此新增双报名路径仍待国服实机验证。
14. 同时可荣和/吃碰、可自摸/立直杠、立直后和牌、求解器正在等待时遇到和牌：只点击当前可用和牌。振听、灰色按钮、过期菜单不得推断和牌。复盘应标明执行层保护、求解器未调用、最终提交与后续观察。另一电脑报告的漏和事件须该机日志才能确认原因；本机通过不能代替该机复测。

## 已知边界

最终名次及赛后评分/总场数字段已在锁定客户端取得只读样本并由用户核对；实际荣和付款过渡、末局自摸和最终座位对应已加入离线回归。新统计加载后的完整对局、评分关联、归档及显示，以及错误自动恢复仍待实机验收；其他小局结果和特殊支付不冒称已实测。不保证建议质量，社区服务未部署。详情见 [关键回归](CORE-VALIDATION.md)、[公开输入缺口](PUBLIC-INPUT-GAPS-20260925.md) 与 [完整历史契约](LIVE-AI-INPUT-COMPLETENESS.md)。

## 回退

先停止全部并卸载候选，再加载旧包，同身份只加载一份。保留模型与配置，必要时恢复外观备份。旧版可能仍有旧的全局验证或默认模型行为，回退后先确认自动关闭；外观恢复不能绕过任务和动作检查。
