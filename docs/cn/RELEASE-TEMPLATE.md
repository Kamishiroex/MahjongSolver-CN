# MahjongSolver · 发布说明模板

多玛方城战求解器（国服优化版）

标准模式不执行游戏操作，仅提供提示。实验求解器与游戏操作为分别选择的可选测试版能力；验证不等于启动，操作需本次任务授权。

发布前替换下列占位内容，只写本次实际实现和执行过的结果。此文件本身不是版本发布记录。

- 版本与适配范围：填写插件版本、游戏版本、Dalamud API 和运行时要求。
- 本次变更：填写用户能够观察到的变化；不把计划写成已实现。
- 构建与验证：填写实际构建、离线测试、源码包重建结果；单独说明是否进行国服实机测试。
- 已知限制：保留影响使用的限制及待验证项目；不承诺胜率或上分。
- 安装与升级：沿用现有安装索引及内部标识 `Mahjong.Plugin.CN`，命令仍为 `/mjcn`，不要求清空配置。品牌更新首次正式发布时说明旧显示名与新品牌属于同一插件。
- 发布附件：填写实际插件 ZIP、完整对应源码 ZIP 和校验文件；仅添加真实存在的下载地址。
