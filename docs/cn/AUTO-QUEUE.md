# 自动排队与进桌开打（0.6.3.0）

本版增加整场循环：[设置、计数依据和实测步骤](CORE-VALIDATION.md)。勾选“无限循环”，或取消勾选后输入1～9999场。每次点击启动从0计数；在桌内启动时计入当前这一场。旧设置没有场数时按无限循环读取，但不自动启动。

当前界面在“任务”页配置自动排队与进桌开打，可选择一种或同时报名两种同类桌型（段位桌不能与亲友桌混合）。使用顶部所选求解来源；匹配到哪一种就按实际桌型读取规则。资格有效并点击“预检并开始连续任务”后才运行。暂停和继续统一在顶部；结束或全停放在“更多”。选用 Mortal 时等准备完成后再报名、确认或开打。新双报名的状态机和参数校验有离线回归，仍待国服实机核对。

设置保存到插件配置目录的 `table-automation.json`，但重载或重新登录后不自行排队，需要再次点击启动。暂停、停止、读取/操作错误、切换决策来源会撤销自动启动权限。游戏已经接受的报名不会因停止插件而被取消，需要在任务搜索器取消；停止之后插件不再自动确认进入。

收到所选麻将任务的完成事件后计入一场，自动打牌停止。启用自动排队时等待至少8秒，且游戏允许退桌才提交一次正常退桌；不主动退出未完成对局，也不强制退桌。牌桌关闭且脱离副本、过渡状态结束后等待约10秒再排下一桌。达到设定场数后结束。没有完成事件的退桌不计数、不继续排队。局间动画不会触发报名或重新启动打牌。亲友桌要求4人小队且本机玩家为队长，段位战要求单人。已有其他报名不接管；报名10秒未获游戏确认、队列被取消或匹配桌型改变时停止，不循环重试。

## 验收

实现及离线状态机验证包含：默认关闭、已有队列不接管、单次报名/确认、桌型不符、队列取消、报名拒绝、短暂界面消失、连续入桌、手动模式不覆盖、登出和立即停止、亲友桌条件。固定接口的实机报名和进入确认仍待验证；未替用户主动加入段位战。

首次实测选择东风一般桌，启用两项后启动；确认只提交一次报名，匹配弹窗只确认一次，入桌约2秒后显示自动模式。遇到队伍/段位/解锁限制应显示游戏提示且10秒后停止重复报名。暂停后应不再启动；整场结束并退桌后确认能再次排队。日志导出入口不变。
