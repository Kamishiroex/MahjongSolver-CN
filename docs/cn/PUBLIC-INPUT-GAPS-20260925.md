## 连续事件补充

纳入 0.6.1.6 的连续事件补充：新增 `PublicIppatsuTracker`，将连续观测到的“先有立直声明、后有吃碰杠”投影为一发资格已取消，供现有 AI 输入使用。它不生成 `reach_accepted`，也不将完整历史状态改为已同步。

规则依据为 Square Enix [多玛方城官方役种说明的 Ippatsu 条目](https://na.finalfantasyxiv.com/lodestone/playguide/contentsguide/goldsaucer/doman-mahjong/yaku_list/)；其中说明在该轮发生吃、碰或杠会使一发无效。此来源用于规则语义，**不是国服内存布局或实机行为的验证依据**。读取仍使用已有国服版本门禁、立直公开事实和 `PublicCallEventTracker`，没有新增内存偏移。

先后关系要求鸣牌的 `FirstObservedSequence` 严格晚于已确认声明的观察序号，并由后续独立采样确认，不能用较晚的 `ConfirmedSequence` 冒充实际鸣牌开始时间。中途读到的既有副露、同帧棒与鸣牌、错误事件类型或证据代码、不同观察段及未来事件均不能取消一发。换局观察段、退桌、采样倒序/重复、超过两秒的断采、版本不符、过渡和声明不可确认时清除相关推导。

实际执行：插件 Release 编译通过；`Mahjong.Plugin.CN.Gameplay.Tests` 全部 **736 项通过**，其中新增 22 项覆盖五类鸣牌、一发取消的保留与清空、时间关系拒绝，以及最终 AI 输入收到 `Ippatsu=false`。新增时序测试为构造样本，不冒称国服连续鸣牌实测。记录在 `.work/ippatsu-gameplay-full.txt` 和测试项目 `TestResults/ippatsu-gameplay-full.trx`。
