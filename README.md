# MahjongSolver

**多玛方城战求解器（国服优化版）**

面向 Windows、FFXIV 国服与 XIVLauncherCN/Dalamud，默认使用上游求解器。**标准模式不执行游戏操作，仅提供提示。** 完整保留界面、主题、目标提醒、评分展示、本地记录与诊断；另提供可选测试版能力。

## 使用

1. 按[中文说明](README-CN.md)安装插件，输入 `/mjcn` 打开界面。
2. 顶部“开始提示”或总览“手动提醒”启动提示，由玩家操作；在“任务”设置已支持的时长、截止目标。
3. 手动打开金碟／方城战资料页，再选择“读取已打开页面”。顶部“暂停”保留任务进度，“停止全部”同时关闭读取；重载不自动启动。
4. 标准功能无需测试码或模型。可选“设置 → 测试版”分别选择实验求解器和游戏操作能力；验证本身不选择、不预热、不启动。游戏操作还需明确授权本次任务，使用上游求解器也一样。资格过期暂停测试操作，续期不自动恢复，不静默切换来源。
5. 出现异常时，在“诊断”导出脱敏日志。不要上传个人配置目录、凭据、模型或原始游戏日志。

目标版本与安装、卸载、构建步骤见[中文说明](README-CN.md)。本人资料页评分可以读取；整场后的可信评分刷新尚待实测，评分目标停止暂未开放。读牌正确、操作效果和建议质量分别验证，不保证获胜或上分。
