# MahjongSolver

**多玛方城战求解器（国服优化版）**

面向 Windows、FFXIV 国服与 XIVLauncherCN/Dalamud，默认使用上游求解器，提供手动提醒、自动打牌和任务管理。另提供测试版功能，验证后可用。

## 使用

1. 按[中文说明](README-CN.md)安装插件，输入 `/mjcn` 打开界面。
2. 在“总览”选择手动提醒或自动打牌；在“任务”设置桌型、排队、场数和停止条件，再主动开始。
3. 使用常驻“暂停自动”停止操作；继续任务会重新预检并保留计数。重载插件默认不启动。
4. 普通功能无需测试码或模型。“设置 → 测试版”为可选入口，验证、导入均不会自动开打。
5. 出现异常时，在“诊断”导出脱敏日志。不要上传个人配置目录、凭据、模型或原始游戏日志。
