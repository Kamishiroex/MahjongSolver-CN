# MahjongSolver

**多玛方城战求解器（国服优化版）**

默认采用上游求解器。**标准模式不执行游戏操作，仅提供提示。** 完整保留主题、提示任务、目标提醒、评分展示、本地记录、设置、诊断与恢复核对，无需测试验证。测试资格有效时，实验求解器和全部游戏操作功能直接可用，无需逐项启用或重复授权；点击开始才运行。不保证获胜或上分。

当前插件版本 **4.1.4**（程序集版本 `4.1.4.0`），目标为 Windows、游戏 `2026.09.15.0000.0000`、国服 Dalamud `15.0.3.5 / API 15` 和 .NET 10。固定来源见源码仓库内 `docs/cn/VERSION-EVIDENCE.md`；其他版本未经验证，不关闭框架检查来强行加载。

## 安装与更新

在 XIVLauncherCN 的 `/xlsettings` → 插件 → 第三方插件仓库中添加并保存：

```text
https://raw.githubusercontent.com/Kamishiroex/MahjongSolver-CN/repo/repo.json
```

刷新插件安装器，搜索“MahjongSolver”并安装。订阅使用固定的 `repo` 分支，独立于开发分支名称；当前指向已发布的 4.1.4 候选包。安装包、对应源码和校验文件也可从[发布页](https://github.com/Kamishiroex/MahjongSolver-CN/releases/tag/v4.1.4)获取。

4.1.4 同版本修正版不会提升程序集版本。已安装同版本时，先暂停并停用插件，再通过安装器重新安装以获取现有附件；不要清除配置与个人资源。核对发布附件 `build-manifest.json` 的源码提交；对应源码以附件 source ZIP 为准。

从旧订阅迁移时，先暂停插件，移除旧订阅地址，再在安装器卸载旧插件并从新订阅安装；不要删除插件配置或模型目录。若正在使用开发插件，先停用其开发加载入口。同一内部身份只能加载一份。

首次开发安装可将已校验 ZIP 解压到独立目录，在 Dalamud 开发插件设置中添加 `Mahjong.Plugin.CN.dll`，再在插件安装器的开发插件页启用。内部身份仍是 `Mahjong.Plugin.CN`，与旧版只能加载一份。先停止、禁用旧插件，再启用新包；保留原配置和模型目录。不要将源码包或测试宿主 DLL 当成插件安装。

新仓库从审核后的源码快照开始，不导入旧 Git 历史。此候选尚缺完整麻将对局和整场评分刷新验收；实际状态见 [验收边界](docs/cn/ACCEPTANCE.md)。

## 使用

输入 `/mjcn` 直接进入青玉主界面：**总览 / 任务 / 战绩与记录 / 设置 / 诊断**。无测试码、无模型也显示完整界面，默认标准求解器且未启动。支持窄窗、紧凑模式、经典布局和外观恢复；不虚构实时背景模糊。

1. 顶部“开始提示”或总览“手动提醒”启动提示，通过版本、登录和公开牌局预检后运行；由玩家操作。完整与紧凑界面均提供“暂停”，“停止全部”同时关闭读取。关闭窗口不等于暂停。
2. 任务页可设置有效时长、截止日期或本场后停；提示任务跟踪当前整场，不代替玩家结算或排队。手动打开金碟／方城战资料页后，点击“读取已打开页面”（或 `/mjcn rating`）。标准评分读取不会开窗、切页或关窗。整场后可信刷新关联尚未核验，评分目标暂不开放。
3. 在设置 → 测试版验证一次，有效七天；有效期内重载也直接开放全部测试功能，无需再勾选能力或点击授权按钮。验证和导入不会切源、预热、开打或排队。设置 → 求解器可选择标准或测试来源；测试版资源仍须正确安装，技术来源在详情中显示。
4. 有效资格下直接点击顶部“自动打牌”，或在任务页“预检并开始连续任务”。出牌、鸣牌、和牌、结算、报名、确认匹配、退桌及连续任务仍核对资格、版本、当前牌桌和本次启动请求；使用上游自动也需要测试资格。来源选择和任务参数属于正常使用设置，不再额外授权。
5. 明确选择的求解来源和个人资源保留，但重载不预热或启动。资格过期时，**过期前已经启动的最后一个任务继续有效，包含无限循环**，界面提示到期但不打断该任务。暂停后可继续同一任务，原来源、模式、计数和停止规则保留；结束任务、重载或改变任务来源后，新任务需重新验证。尚未真正启动的旧请求不能借续期复活。标准提示始终不受测试资格影响，重新验证本身不启动任何操作。
6. 有效资格下，总览的“刷新本人评分”（或 `/mjcn rating`）直接打开、切页、读取并关闭插件自己打开的窗口，不启动打牌或排队。无资格时同一入口只读取已打开的资料页。正在运行的自动任务可在整场结算退桌后刷新；失败保留原读数和时间，不阻塞排队。失去资格时不再操作窗口，已打开的窗口留给玩家处理。
7. 设置中的“短暂读取或计算异常后立即尝试恢复”默认开启：暂停旧动作后重新核对同桌，稳定至少 300ms 才沿用原任务授权继续；每次最多 8 秒、每分钟最多 3 次。过期后仍有效的原任务同样可恢复；手动暂停、任务权限失效、换角色/场景、版本变化及上次操作结果不明不会恢复。失败仍有明确停止提醒。可选社区联网默认关闭，与测试验证分开授权。

任务页选择东风/半庄及桌型，设置进桌开打、自动排队、N 场或无限循环，再点击“预检并开始连续任务”。一场是完整东风/半庄；整场完成且游戏允许时退桌再排。段位战要求单人，亲友桌要求 4 人且自己为队长。保存设置不等于授权操作；重载或手动停止后需重新启动，已提交的报名请在游戏内取消。

记录中的结果只在证据齐全时显示：整场名次需本人结算行，逐局胜负需结算提示与完整付点，整场评分变化需赛前/赛后总场数恰好增加 1。标准模式可在排队前和整场后手动打开“金碟 → 方城战”资料页，并在插件点击“读取已打开页面”采集评分；不会自动开关窗口。缺少数据的旧记录保留未知，不能靠刷新补出已经关闭的结算页。名次与资料页字段已有实机核对，新统计的完整加载、归档与显示链路仍待实机验收。

## 诊断、恢复与卸载

- 错误停止会显示原因、弹窗及提示音，使用“导出停止日志”或“诊断 → 导出详细技术日志”；`/mjcn logs` 也可导出。不要上传整个配置目录、原始内存、聊天或账号数据。
- 事件与错误日志每整场独立记录，可保留最近 20/50/100/200/500 场（默认 50），历史记录预算 1 GiB；当前场和手动导出 ZIP 不自动清理。
- “战绩与记录 → 刷新本机整场摘要”校验最近最多 200 份现存记录（含归档），按实际桌型、版本、配置指纹及记录到的接管分组。需要长期观察时，可用现有日志保留设置选择 100/200 场；仍受 1 GiB 预算限制。100～200 场只作初步趋势，不足以证明模型强弱；对手环境尚未知。
- 可按时间、桌型、求解来源筛选，或只看缺失记录；覆盖率和缺口原因独立展示。“重建摘要并重试保存”会重读已有证据。结算结果先暂存，保存失败后后台退避重试，重载继续补写；不会把另一场的读数接到旧记录，也不能补回从未采到的信息。
- 整场结束会在原日志目录生成 `match-summary.json`；名次与赛后评分分别附加 `final-result.json` 和 `rating-after.json`，与原场次和日志绑定。摘要仅为派生数据，看板重新校验原始事件，并显示已核对/已观察小局数。未知结果不进入统计分母。离桌不算完成，提交不算接受，延迟动作取消不算确认错过必需操作。“全程自动”仅指观察覆盖自动模式，不证明每步输入被接受；游戏内直接手动点击的接管次数未知。
- 每场“本地技术详情 → 读取决策复盘”显示最近 50 条去重决策的实际后端、输入标识、原始候选、过滤原因、保护覆盖、提交及后续观察。旧桥未报告的内部保护标为未知；独立确认/立直续步等未关联提交另列，不能归功于模型。配置指纹覆盖插件构建、桥/模型清单与操作设置；混合配置和旧记录不混入可比较样本。没有新增上传或遥测。
- 本地技术详情可导出固定决策样本，供同一份输入在不同构建下重放、对比动作/候选/过滤/覆盖和耗时；工具用法见 [离线复盘](tools/Mahjong.Cn.JournalReplay/README.md)。导出不调用求解器、不操作游戏。旧记录没有完整输入时明确跳过。
- `/mjcn recover` 将同桌本地记录与当前公开桌面核对。中途恢复只能使用已观察到或当前可见的信息，不补造缺失事件顺序。真实异常仍会停止并提醒。
- 配置目录：`%APPDATA%\XIVLauncherCN\pluginConfigs\Mahjong.Plugin.CN`。模型、租约、日志留在本机，不要提交到源码仓库。
- 卸载前暂停全部自动功能，在插件安装器卸载。需要清除模型、租约、日志时，再手动删除该插件配置目录；先保存需要的个人包和诊断文件。

## 构建与验证

需要 Windows PowerShell、.NET SDK `10.0.100`、Python 及固定国服 Dalamud 库。`scripts/bootstrap-dotnet.ps1` 可将 SDK 准备到忽略的工作目录。编辑期间允许本地改动、不生成分发包：

```powershell
./scripts/build-cn.ps1 -VerifyOnly -PythonPath python
```

正式打包要求干净的本地提交与审核后的 `scripts/source-files.txt`。新增必需文件时先审核、更新清单并提交；任意未跟踪文件不会自动收入源码包。

```powershell
./scripts/build-cn.ps1 -PythonPath python -DalamudLibPath "$env:APPDATA\XIVLauncherCN\addon\Hooks\26-09-25-01"
```

可选 `-AkochanDirectory <本地合法引擎目录>` 运行实际原生 AI 回归，`-JournalReplayFile <本地公开事件记录.jsonl>` 验证日志重放。不提供会明确标记未执行。脚本不发布或上传数据。引擎构建见源码内 `docs/cn/AKOCHAN-LICENSE-BUILD.md`，凡夫工具见 `tools/MortalBridge`。

输出位于忽略的 `artifacts/`：插件 ZIP、同版本 source ZIP、`SHA256SUMS` 和构建/测试记录。检查 `build-manifest.json` 的完成状态、测试及源码包重建结果；旧 ZIP 不代表本次成功。源码包绑定提交和逐文件哈希；插件包只含运行依赖、布局、说明与许可证，不含模型、框架 DLL、采集文件或私人配置。
