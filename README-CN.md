# MahjongSolver

**多玛方城战求解器（国服优化版）**

默认采用上游求解器，提供手动提醒、自动打牌、任务、排队、停止规则、评分读取、本地记录和恢复核对。标准功能不要求测试验证。另提供测试版功能，验证后可用。建议与操作效果需分别实测，不保证获胜或上分。

当前插件版本 **4.1.4**（程序集版本 `4.1.4.0`），目标为 Windows、游戏 `2026.09.15.0000.0000`、国服 Dalamud `15.0.3.5 / API 15` 和 .NET 10。固定来源见源码仓库内 `docs/cn/VERSION-EVIDENCE.md`；其他版本未经验证，不关闭框架检查来强行加载。

## 安装与更新

在 XIVLauncherCN 的 `/xlsettings` → 插件 → 第三方插件仓库中添加并保存：

```text
https://raw.githubusercontent.com/Kamishiroex/MahjongSolver-CN/repo/repo.json
```

刷新插件安装器，搜索“MahjongSolver”并安装。订阅使用固定的 `repo` 分支，独立于开发分支名称；当前指向已发布的 4.1.4 候选包。安装包、对应源码和校验文件也可从[发布页](https://github.com/Kamishiroex/MahjongSolver-CN/releases/tag/v4.1.4)获取。

从旧订阅迁移时，先暂停插件，移除旧订阅地址，再在安装器卸载旧插件并从新订阅安装；不要删除插件配置或模型目录。若正在使用开发插件，先停用其开发加载入口。同一内部身份只能加载一份。

首次开发安装可将已校验 ZIP 解压到独立目录，在 Dalamud 开发插件设置中添加 `Mahjong.Plugin.CN.dll`，再在插件安装器的开发插件页启用。内部身份仍是 `Mahjong.Plugin.CN`，与旧版只能加载一份。先停止、禁用旧插件，再启用新包；保留原配置和模型目录。不要将源码包或测试宿主 DLL 当成插件安装。

新仓库从审核后的源码快照开始，不导入旧 Git 历史。此候选尚缺完整麻将对局和整场评分刷新验收；实际状态见 [验收边界](docs/cn/ACCEPTANCE.md)。

## 使用

输入 `/mjcn` 直接进入青玉主界面：**总览 / 任务 / 战绩与记录 / 设置 / 诊断**。无测试码、无模型也显示完整界面，默认标准求解器且未启动。支持窄窗、紧凑模式、经典布局和外观恢复；不虚构实时背景模糊。

1. 在总览选择“手动提醒”，或用顶部常驻“自动打牌”开启自动，通过版本、登录、公开牌局与动作预检后运行。完整与紧凑界面均可操作；手动转自动、暂停后继续会保留同一任务的计数、预算和停止条件。“暂停自动”保留只读记牌，“停止全部”同时关闭读取与操作；具体说明见按钮悬浮提示。
2. 在任务页设置桌型、场数、时长、截止日期或本场后停，再明确启动。总览的“刷新本人评分”（或 `/mjcn rating`）自动打开本人金碟麻将资料页、读取后关闭插件打开的窗口；运行中整场结算退桌后自动刷新，失败保留原读数和时间，不阻塞排队。评分读取不要求测试资格；整场后可信刷新关联未核验，评分目标暂不开放。
3. 设置 → 求解器显示当前来源。设置 → 测试版为可选次级入口；验证有效七天，但验证和导入均不会切源、预热、开打或排队。具体资源和技术来源仅在主动打开的详情中显示。
4. 首次默认标准求解器。使用测试版时先主动选择，再明确启动或继续；所需资源仍须完整。之后重载/重启保留明确选择的来源和模型，但不预热、出牌或排队。打开测试页或仅验证不会改变来源。
5. 测试资格失效不会停止标准任务；选用测试版时会提示续期，暂停相关操作并取消旧结果，保留原模型与任务计数。重新验证后点击顶部“自动打牌”或“继续任务”恢复；不会自动切成标准，也不会因续期自行开打。仍可主动改用标准求解器。
6. 勾选局间持续可在已识别的结算/换局等待其他玩家；不会恢复真实错误、退桌或手动暂停。可选社区联网默认关闭，与测试验证分开授权。

任务页选择东风/半庄及桌型，设置进桌开打、自动排队、N 场或无限循环，再点击“预检并开始连续任务”。一场是完整东风/半庄；整场完成且游戏允许时退桌再排。段位战要求单人，亲友桌要求 4 人且自己为队长。保存设置不等于授权操作；重载或手动停止后需重新启动，已提交的报名请在游戏内取消。

## 诊断、恢复与卸载

- 错误停止会显示原因、弹窗及提示音，使用“导出停止日志”或“诊断 → 导出详细技术日志”；`/mjcn logs` 也可导出。不要上传整个配置目录、原始内存、聊天或账号数据。
- 事件与错误日志每整场独立记录，可保留最近 20/50/100/200/500 场（默认 50），历史记录预算 1 GiB；当前场和手动导出 ZIP 不自动清理。
- `/mjcn recover` 将同桌本地记录与当前公开桌面核对。中途恢复只能使用已观察到或当前可见的信息，不补造缺失事件顺序。真实异常仍会停止并提醒。
- 配置目录：`%APPDATA%\XIVLauncherCN\pluginConfigs\Mahjong.Plugin.CN`。模型、租约、日志留在本机，不要提交到源码仓库。
- 卸载前暂停全部自动功能，在插件安装器卸载。需要清除模型、租约、日志时，再手动删除该插件配置目录；先保存需要的个人包和诊断文件。

## 构建与验证

需要 Windows PowerShell、.NET SDK `10.0.100`、Python 及固定国服 Dalamud 库。`scripts/bootstrap-dotnet.ps1` 可将 SDK 准备到忽略的工作目录。编辑期间允许本地改动、不生成分发包：

```powershell
./scripts/build-cn.ps1 -VerifyOnly -PythonPath python
```

正式打包要求干净的本地提交与审核后的 `scripts/source-files.txt`。新增必需文件时先审核、更新清单并提交；任意未跟踪文件不会自动收入源码包。

```powershell
./scripts/build-cn.ps1 -PythonPath python -DalamudLibPath "$env:APPDATA\XIVLauncherCN\addon\Hooks\26-09-25-01"
```

可选 `-AkochanDirectory <本地合法引擎目录>` 运行实际原生 AI 回归，`-JournalReplayFile <本地公开事件记录.jsonl>` 验证日志重放。不提供会明确标记未执行。脚本不发布或上传数据。引擎构建见源码内 `docs/cn/AKOCHAN-LICENSE-BUILD.md`，凡夫工具见 `tools/MortalBridge`。

输出位于忽略的 `artifacts/`：插件 ZIP、同版本 source ZIP、`SHA256SUMS` 和构建/测试记录。检查 `build-manifest.json` 的完成状态、测试及源码包重建结果；旧 ZIP 不代表本次成功。源码包绑定提交和逐文件哈希；插件包只含运行依赖、布局、说明与许可证，不含模型、框架 DLL、采集文件或私人配置。
